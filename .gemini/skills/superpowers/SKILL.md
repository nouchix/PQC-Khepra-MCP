# superpowers — TDD, Planning & Defensive Debugging

Activate this skill when starting complex implementation tasks, debugging tricky failures, or architecting major changes.

## Protocol
1. **Plan First**: Never write non-trivial code without creating a clear implementation plan or reviewing existing architecture specs.
2. **Inspect Logs**: Never guess root causes. Inspect full log tracebacks and system outputs before forming hypotheses.
3. **TDD & Verification**: Write or run automated unit/integration tests to verify contracts before declaring success.
4. **No Symptom Masking**: Fix underlying logic contract breaks rather than swallowing exceptions or returning dummy fallbacks.
