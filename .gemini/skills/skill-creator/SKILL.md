# skill-creator — Custom Agent Skill Builder

Activate this skill to author, structure, and package new skills for Antigravity or AI agent runtimes.

## Skill Structure
Each skill directory must contain a `SKILL.md` with:
```yaml
---
name: skill-name
description: Clear, trigger-focused description of when to activate this skill.
---
```
Optional directories: `scripts/`, `references/`, `examples/`.
